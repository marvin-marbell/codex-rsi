# Delegated work integration

When work is delegated, give collaborators clear ownership, the relevant interface and the user's current objective. Reconcile their changes at the consumer boundary and reuse their evidence. Tell collaborators promptly when steering or an interface changes.

The integration owner carries authorized work through delivery; a handoff is not an excuse to park a finished slice or add approval stages. Use proportional checks for actual integration risks, and name a real blocker when another person's input is necessary.
