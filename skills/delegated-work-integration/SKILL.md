# Delegated work integration

Own the top-level decision. Before fan-out, name independent slices, disjoint write ownership, shared interfaces and one integration owner. Parallelism without a compatibility contract creates conflicts; same-file edits need one owner. Give each worker source revision, permission boundary, acceptance behavior and explicit non-goals.

Read returned artifacts rather than treating agent confidence or a done flag as proof. A worker may use a stale checkout, unsupported runtime or test that never exits. Reconcile target revisions, confirm every slice reached its intended owner, and integrate at the actual consumer path. Leaf agents should not wait on long-running processes or run project-wide validation while siblings edit; run composed smoke after integration.

Handoff is complete when the recipient has an actionable result and residual owner/decision is named. Do not add heartbeat schedules, check counts or a planner agent simply to look controlled. When a contradiction changes the plan, update the shared contract before further work.
