# Project language intelligence

Inspect the relevant source and existing project instructions before editing. Use available LSP, AST or structural search when they make symbol relationships or a scoped change clearer; use text search and source reading when they are sufficient. Do not install tools, run capability probes or add dependencies solely to satisfy a ritual. If an exported interface changes, trace its real consumers and update them. Validate the changed behavior in proportion to impact, using prior evidence where applicable.
